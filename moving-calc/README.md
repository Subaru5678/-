# 引っ越し準備計算

段ボール箱の必要数・賃貸初期費用合計・適正家賃・家具の搬入判定・引っ越し費用目安・
引っ越しまでの残り日数を、その場で計算する引っ越しと部屋探しのためのツールです。
`diy-calc/` `cooking-calc/` と同じくバックエンド不要、完全にブラウザ内で動作するPWAです。

## 今すぐ試す

```
cd moving-calc
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

## 公開URL

リポジトリの GitHub Pages デプロイに組み込まれています。公開後は
`https://<ユーザー名>.github.io/<リポジトリ名>/moving-calc/` で公開されます。

## なぜこのアイデアか

`diy-calc`・`cooking-calc` と同じ「検索意図が明確な実用計算ツール」路線の第3弾です。
引っ越し・部屋探しは検索需要が明確で季節性(3〜4月)もありますが、既存の「引っ越し」アプリの
多くは業者への一括見積もり依頼サービス(リード獲得目的)で、単体の計算ツールという立ち位置は
手薄です。初期費用や適正家賃、段ボール数などは誰もが一度は検索する実用的な計算です。

## 広告・プライバシーポリシー

`diy-calc` と同じ仕組みで、AdSenseの `<script>` とパブリッシャーID/広告ユニットIDを
設定すると自動的に有効化されます(プレースホルダーのままなら安全に無効のまま)。詳細は
`diy-calc/README.md` の「無料で公開する」節を参照してください。プライバシーポリシーは
`privacy.html` に用意し、ホーム画面下部にリンク済みです。
