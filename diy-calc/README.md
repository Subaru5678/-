# 現場の資材計算 (DIY & リフォーム資材計算アプリ)

塗料・壁紙(クロス)・モルタル/コンクリート配合・フローリング・木材カットの必要量を
その場で計算する、DIY・軽作業の職人向けツールです。バックエンド不要、完全にブラウザ内で動作します。

## 今すぐ試す

```
cd diy-calc
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

スマホのブラウザで開き、共有メニューから「ホーム画面に追加」するとアプリのように
インストールできます(PWA)。オフラインでも動作します。

## なぜこのアイデアか(広告収益 × 低競合という条件での判断)

- 「電卓」「単位変換」「フラッシュライト」のような汎用ツールはストアが飽和しており、
  広告単価(eCPM)も低い傾向があります。
- 「塗料 何リットル」「壁紙 必要量 計算」のようなDIY・リフォーム特化の検索語は
  具体的でニッチなため、上位表示を狙いやすく、実需要があるユーザーが検索してきます。
- 医療・金融のような誤りが重大な結果を招く分野ではないため、リスクが低いです。
- リフォーム/DIYは1回のプロジェクトで複数回アプリを開く(塗料→壁紙→床材と何度も
  計算し直す)ため、1ユーザーあたりの広告表示回数を稼ぎやすい構造です。

## 正直な前提(このセッションでできること・できないこと)

このセッションでは実際のApp Store / Google Playへの申請はできません
(開発者アカウント・署名鍵・審査はユーザー自身の操作が必要です)。
ここまでに用意したのは:

- 今すぐ動く完成品(このPWA)
- 広告を組み込む場所(`index.html` の `#adSlot`)
- ストア申請までの具体的な手順(下記)

## ストア公開までの実際のステップ

1. **Capacitorでネイティブ化 — 完了済み**
   `../mobile` に Capacitor プロジェクト(Android/iOS両方)を用意済みです。
   詳細は `../mobile/README.md` を参照してください。
2. **AdMob導入 — 配線済み(テストIDで動作)**
   - `index.html` の `initAds()` がネイティブ実行時に `@capacitor-community/admob`
     を呼び出し、バナー広告を表示します(現在はGoogleの公開テストID)
   - Google AdMobでアカウント作成 → アプリ登録 → 広告ユニット(バナー)を発行し、
     `../mobile/README.md` の手順で本番IDに差し替えてください
3. **開発者アカウント**
   - Apple Developer Program(年間$99) / Google Play Developer(初回$25)に登録
4. **アイコン・スクリーンショット**
   - アプリアイコン・スプラッシュ画面は `../mobile/assets/` のプレースホルダーから
     自動生成済みです。本番公開前に `../mobile/assets/icon.png` を本番デザインに
     差し替えて `npx capacitor-assets generate` を再実行してください
   - ストア掲載用スクリーンショットは別途用意してください
5. **審査・申請**
   - Xcode / Android Studio でビルドし、それぞれのストアコンソールから申請
     (このセッションのサンドボックスはGoogleのMavenリポジトリ(dl.google.com)への
     アクセスが制限されているため実機ビルドの確認はできていません。手元のPC/Macか
     CIでビルドしてください)

## 収益化に関する現実的な見立て

広告収益は「公開しただけ」では発生しません。ASO(アプリストア最適化: タイトル・
キーワード・説明文)と、SNSやDIY系コミュニティでの初期告知が必要です。個人開発の
ニッチ計算アプリは月数千〜数万円規模の副収入になることが多い現実的なラインで、
バズって大きく跳ねる前提ではなく「積み上げ型」の収益源と捉えるのが妥当です。

## 機能拡張の余地

- 保存した計算のクラウド同期(要バックエンド)
- 買い物リスト化(近隣ホームセンターへのリンク)
- 複数の部屋をまとめて計算するプロジェクト機能
