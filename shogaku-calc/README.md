# 奨学金検索

返済タイプ(給付型/無利子貸与/有利子貸与)や対象となる家庭状況などの条件で絞り込んで、
実在する奨学金制度(JASSO第一種・第二種、高等教育の修学支援新制度、あしなが育英会、
キーエンス財団、似鳥国際奨学財団、日本財団 夢の奨学金など)を検索・比較できるツールです。
気になる制度はお気に入り登録でき、返済シミュレーター・学費の不足額計算も収録しています。

掲載内容は一般的な目安であり、正式な金利・貸与額・審査基準・締切は各制度の公式サイトで
確認する必要があります。

```
cd shogaku-calc
python3 -m http.server 8080
```
