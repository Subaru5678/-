# 料理の計量計算

人数分の分量換算・ベーカーズパーセント・カップ⇔グラム変換・塩分濃度・めんつゆ希釈・
オーブン温度換算・賞味期限計算・食材個数換算を、その場で計算する料理と製菓のためのツールです。
`diy-calc/` と同じくバックエンド不要、完全にブラウザ内で動作するPWAです。

## 今すぐ試す

```
cd cooking-calc
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

## 公開URL

リポジトリの GitHub Pages デプロイに組み込まれています。公開後は
`https://<ユーザー名>.github.io/<リポジトリ名>/cooking-calc/` で公開されます
(`diy-calc/` は引き続きルート `https://<ユーザー名>.github.io/<リポジトリ名>/` のままです)。

## なぜこのアイデアか

`diy-calc`(DIY・リフォーム資材計算)と同じ「検索意図が明確な実用計算ツール」路線の第2弾です。
レシピ検索そのものは激戦区ですが、「レシピ集」ではなく「分量計算だけに特化したツール」という
ポジションは手薄です。また、料理は生活の中でほぼ毎日行われるため、DIYアプリより利用頻度が
高く、広告表示回数を稼ぎやすい構造になっています。

## 広告・プライバシーポリシー

`diy-calc` と同じ仕組みで、AdSenseの `<script>` とパブリッシャーID/広告ユニットIDを
設定すると自動的に有効化されます(プレースホルダーのままなら安全に無効のまま)。詳細は
`diy-calc/README.md` の「無料で公開する」節を参照してください。プライバシーポリシーは
`privacy.html` に用意し、ホーム画面下部にリンク済みです。
